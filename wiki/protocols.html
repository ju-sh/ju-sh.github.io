PCIe

Peripheral Component Internconnect express

  1. Application layer
  2. Transaction layer: TLP packets
  3. Data-link layer: DLLP packets
  4. Physical layer
    • Logical sub-block
    • Electrical sub-block

—

States:

  • D1, D2, D3hot
  • L0: Active
  • L1: Inactive (low-power)

APB

APB3: https://web.eecs.umich.edu/~prabal/teaching/eecs373-f12/readings/ARM_AMBA3_APB.pdf

Features:

  • No pipelining
  • Involves a master

Signals:

  • PCLK: clock
  • PRESETn: async reset (active low)
  • PADDR: Address
  • PSELx: Select. Choose a slave peripheral
  • PENABLE: Indicate non-first cycles of an APB transfer (ie, after setup phase)
  • PWRITE: High for write, low for read
  • PWDATA: Data to write
  • PRDATA: Data being read
  • PREADY: Slave can turn this low if it needs more time
  • PSLVERR: APB transfer error

UART

No clock, so baud rate has to be previously agreed upon.

  • TX: Transmit
  • RX: Receive
  • Ground
