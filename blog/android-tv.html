Cleaning up an Android TV

  • Date created: 10-Sep-2026

Tags: / android /

First steps towards de-bloating an android TV.

I recently got temporary access to an old Redmi TV running Android. YouTube was too annoying with ads, so I set off to make it more friendly. Started off with taking SmartTube out for a spin, then went a bit more in the direction of cleaning up the TV.

I tried to minimize apps with ads, telemetry, unnecessary internet access, etc. Open source apps are generally better from the perspective than those available in the default Play store.

Expectations from TV

When compared to normal TVs, 'smart'-TVs should be an upgrade, but it often feels like a downgrade. Devices marketed as 'smart' are often smart more in the favour of targeted ads than in the improvement of user experience.

Anyway, I wanted the android TV to be at least as useful as a normal TV. I targeted the following:

  • Play local video files
  • Youtube without ads
  • Connect to the internet only if it needs to.
    • No need to pull a different wallpaper every 10 minutes
    • Disable telemetry
    • Since google apps have in-built telemetry-like stuff, avoid google apps as much as possible
  • Remove adware and unwanted apps
  • Install desired apps
    • App manager
    • File manager
    • File sharing:
    • Media player

Preparation

Before we can begin modifying the software in the TV effectively, we need to enable developer mode and set up a way for the adb tool to communicate with the OS in the TV.

Overall, the steps involved would be something like this:

  1. Enable developer mode
  2. Enable USB debugging
  3. Connect to TV from computer: adb connect <ip-addr-of-tv>
  4. Install apk file: adb install <apk-name>
  5. Disable USB debugging
  6. Disable developer mode

Now that we have an idea of what to do, let's get on with it!

Connect to TV

We can connect to the TV from a laptop with adb installed in it. Ensure that both the laptop and the TV are connected to the same WiFi network.

First, find out the IP address of the TV. This will be visible in the settings. Suppose the IP address of the TV is 192.168.29.101.

We can connect to the TV from the laptop with:

adb connect 192.168.29.101
* daemon not running; starting now at tcp:5037
* daemon started successfully
failed to authenticate to 192.168.29.101:5555

This will make the TV to prompt to you to accept the connection. Upon allowing this connection, we can install / uninstall / enable / disable the apps installed in the TV. Just like in the case of an android phone.

$ adb connect 192.168.29.101
already connected to 192.168.29.101:5555

$ adb devices
List of devices attached
192.168.29.101:5555     device

Uninstall or disable unwanted apps

The TV came pre-loaded with apps like Netflix, JioCinema, etc. Some of these apps could not be deleted without adb. I got rid of them since the users of the TV were not using them.

Disabled most apps instead of uninstalling, in case they are needed again.

Some of these apps were removable from the interface without any need for adb. Eg: JioCinema

Anyway, I dropped in to the adb shell with:

adb shell

and disabled the apps with:

# PatchWall: Redmi launcher
pm disable-user com.mitv.tvhome.atv
pm disable-user com.mitv.tvhome.mitvplus
pm disable-user com.mitv.tvhome.michannel

# Netflix
pm disable-user com.netflix.ninja

# Amazon alexa
pm disable-user com.xiaomi.amazon.alexa

# Amazon prime
pm disable-user com.amazon.amazonvideo.livingroom

# Mi Wallpaper
pm disable-user com.mitv.dream

# Ads and stuff
pm disable-user com.xm.webcontent
pm disable-user com.google.android.tvrecommendations
pm disable-user com.google.android.partnersetup
pm disable-user com.google.android.feedback
pm disable-user com.xiaomi.statistic

# Xiaomi updates
pm disable-user com.xiaomi.mitv.updateservice

# Youtube Music
pm disable-user com.google.android.youtube.tvmusic

# Google Play Movies and TV
pm disable-user com.google.android.videos

# Xiaomi default music player
pm disable-user com.xiaomi.mimusic2

# Disable wallapers getting downloaded
pm disable-user com.google.android.backdrop

# Analytics
pm uninstall --user 0 com.miui.tv.analytics
pm disable-user com.xiaomi.tvqs.overseas

# Google Play store
pm disable-user com.android.vending

# Google Play services (if you dare)
pm disable-user com.google.android.gms

# Facilitates default 3rd party apps
pm disable-user android.autoinstalls.config.xiaomi.amelie

Let me draw attention to a few aspects here:

  • I don't need google play store, as I'm using only FOSS apps.
  • I guess it's okay to also disable google play services if you don't use any app relying on it. Disabling it would likely lead to a reduction in RAM usage. Don't disable if you use an app like Netflix.
  • I'm not disabling the default android launcher at this point, as I haven't installed a replacement yet.

I found this to be a useful resource in fixing the list of apps that can be uninstalled safely: https://cleanyourtv.tools/tvs/redmi/mitv-mooq3/

Apps to install

When deciding on the apps to be installed, I figured that an ideal app would have the following properties.

  • Open source
  • Actively maintained
  • Large user base
  • Light weight
  • UI primarily meant for TV
  • No 'pay-to-unlock' features
  • Available on F-droid, or at least izzydroid
  • Not vibe-coded
  • No internet connections unless explicitly approved
  • No ads or telemetry

Most of the time, I used the entries in this list to find apps: https://github.com/Generator/Awesome-Android-TV-FOSS-Apps

App store

An app to manage other apps installed on the TV would be very convenient. With such an app store, we can installa and update apps easily. This obviates any need for going through the hassle of figuring out the right apk, manually downloading it, and installing them via adb.

F-droid is great. But there seem to so few apps in the main repo that are primarily for TV. Still, F-droid compatible repos like those in izzydroid have lot more. I would still prioritize the main F-droid app though.

There seem to be many other ways like Obtainium (install directly from release page of apps) and Downloader (use a numeric code to download apps, but is not FOSS). But F-droid and Izzydroid were sufficient for me and I didn't explore those options.

I went with Flicky, an F-droid client that is primarily meant for android TV. It has many repos enabled by default, I disabled everything other than the main F-droid and izzydroid.

For the app store, we perform the installation manually via an apk file. Our TV has a 32-bit chip, so went with armeabi-v7a variant of apk files.

adb install flicky-4.6.1-armeabi-v7a.apk

Replace default launcher

The default launcher is essentially a means to serve users with advertisements. This is true in the case of Redmi's PatchWall and google's launcher. We needed something ad-free and lightweight. But before we disable the default launcher, we got to be sure that we got a working replacement in-place.

I replaced the default launcher with LTvLauncher, a second-generation fork of FLauncher. We got to enable some stuff in the settings for the remote buttons to work properly. Apparently, android doesn't provide a means to override its inclination to stick to the default launcher. Without a bit of adjustment, home button on the TV remote will go back to the default launcher. Many launchers, LTvLauncher among them, adapt the accessibility features of android to work around this.

Once I got the desired launcher installed, I disabled the default google launcher.

pm disable-user com.google.android.tvlauncher

A few other launchers worth exploring:

  • https://github.com/leanbitlab-org/LtvLauncher
  • https://github.com/osrosal/flauncher
  • https://github.com/meddouribadis/arclauncher
  • https://github.com/HoangTran0410/tv-remote

Fun fact: I initially used Projectivity launcher, figuring it was FOSS. But it isn't. It has a public repo, but its contents are not the app's source code. Came across a few other popular apps like this.

Key mapper

The TV remote had a few buttons with labels like Netflix and Amazon Prime. We are not using any of those apps, so we could use those buttons for other actions. For this, we need an app that will let us 'assign' buttons to specific actions.

I went with KeyMapper, available from the main F-droid repo itself.

Media player

We wanted an app that can play video and audio files present in internal/local storage. Till now, the TV was being used only as a means to run youtube (with ads) on a bigger screen than phone. Preferred a lightweight app which still supported the wide variety of file formats related to multimedia. Finally went with VLC.

The following media players sounded nice too:

  • https://github.com/xbmc/xbmc
  • https://kodi.tv/about/
  • https://github.com/nova-video-player/aos-AVP

File manager

All we needed was a simple app that will let us do basic file operations like copy, paste, move, rename, etc. Settled on Fluffy. Seems to work well, but I had been having trouble deleting files and creating folders with v4.5.1. Hopefully we'll soon figure out what's going wrong there.

Transferring files

We need an easy way to move files in and out of the TV. LocalSend sounded like a good option, particularly if you already use it on other platforms. It lets us share files between phones, computers or TVs as long as all are on the same WiFi network and got LocalSend installed.

Smarttube

A YouTube replacement app is what got me started on cleaning up the TV and that was one of the first things that I installed after the initial setup.

I used the F-droid build of smarttube via Flicky. There was a difference in size of apk for the same version (v32.71) of SmartTube when downloaded from github releases when compared to that from F-droid.

  • F-droid (arm64-v8a | armeabi-v7a | x86): 50 MB
  • Github release
    • arm64-v8a: 25.5 MB
    • armeabi-v7a: 24.3 MB
    • universal: 33.8 MB
    • x86: 27.1 MB

The F-droid apk is almost double the size. I figure this difference is because the F-droid version can be used to install on more architectures. Although I wonder why the 'universal' apk from the github release is smaller in that case..

Hardware stats viewer

We wanted to have something like Linux's htop in android TV to view the RAM and CPU usage. CPU info was the closest one that I could find. It feels lightweight and nice.

Further steps

The apps mentioned earlier seems to be sufficient for our use case, but there is always room for improvement. The following would be cool as well.

  • Keyboard: Currently using gboard, but a keyboard with extra features like 'select-all' would have been nice. Like how it is possible with heliboard on phones. I suppose asking for multiple languages would be too much for a UI on TV.
  • Offline speech-to-text: Typing text is a bother using a D-pad on a remote. Use of google's voice assistant means reliance on play services which we wish to avoid. Perhaps sayboard is a possible alternative. Since it doesn't have keys to press in case corrections are needed, it would be best if there a quick way like a button press to switch to a full keyboard.
  • Web browser: A simple browser to view websites would be nice. I figured it wouldn't be too difficult since webview is already there in Android, but I couldn't find any that is actively maintained.
  • IPTV: TV channels via internet. Uses data in m3u files. In fact, VLC can be used to view IPTV channels.
  • Gallery app: We don't need a gallery app yet, but would be good to replace the default one.
  • Ad blocking: Would be great to block specific domains globally or app-wise. Netguard and DNSNet might be of help.
  • See if anything interesting can be done with one of the actively maintained forks of shizuku ¹ ².
